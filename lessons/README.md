# Six Short Lessons

Each lesson takes one small step. Run the lessons in order for a one-minute
demo. All lessons use mock mode.

| Lesson | Question | Main tool |
|---|---|---|
| [1. Connect](01-connect.md) | How does a host-owned account become usable? | `account_summary` |
| [2. Inspect](02-inspect.md) | What does the agent know before writing? | `account_summary` |
| [3. Draft](03-draft.md) | How does a topic become a reviewable post? | `draft_post` |
| [4. Schedule](04-schedule.md) | What does "scheduled" mean in mock mode? | `schedule_post` |
| [5. Measure](05-measure.md) | Which numbers are simulated and why? | `recent_metrics` |
| [6. Join AHAN](06-join-ahan.md) | How can a creator join without leaking X credentials? | `ahan_handoff` |

Start here:

```powershell
pwsh -NoProfile -File ..\run_mock.ps1
```
