# Visual Content Starter

These templates are content scaffolds, not evidence. Replace every bracketed
field with a real observation from the creator.

## Template 1: Build note

```text
The smallest useful change I made this week:

[Before: one concrete bottleneck]
[Change: one specific action]
[After: one measurable or observable result]

[One question that invites a useful reply.]
```

Alt text for a companion image:

`A simple before-and-after workflow card with the bottleneck on the left and the smaller workflow on the right.`

## Template 2: Five-post mini thread

```text
1/ I tested [specific workflow] for [time window].
2/ The starting point was [baseline].
3/ I changed [one variable].
4/ The result was [observed result, with unit].
5/ The next test is [next action]. What should I compare?
```

Alt text for a companion chart:

`A small line chart comparing the baseline and the changed workflow over the stated time window.`

## Template 3: Tool teardown

```text
One detail I missed in [tool/API]:

[Fact from the official source]

Why it matters:
[Concrete consequence for a creator or developer]

Minimal check:
[One command or user action that proves the point]
```

Alt text for a companion screenshot:

`A cropped screenshot of the named API response with sensitive values removed and the relevant field highlighted.`

## Creator review checklist

| Check | Pass condition |
|---|---|
| Evidence | Every number traces to the creator's own record or a named source |
| Claim | Fact, inference, and opinion are not mixed |
| Specificity | The post names a workflow, tool, time, or result |
| Source | The source is visible and current enough for the claim |
| Privacy | No handle, email, token, customer, or private screenshot data |
| Accessibility | Every image has useful alt text |
| Alt text | The alt text describes the information, not "image of" |
| Character limit | The text is 280 characters or fewer |
| Mode label | Mock content is labeled simulated |
| Human review | The creator approves the final text and time |
