# X Starter：让 Agent 可靠接入 X

> 时长 115.2s | 5 页 | sapi TTS | Microsoft Huihui Desktop

## X STARTER · MCP
**让支持 MCP 的 Agent 接入 X**
这是 X Starter。它不是另一个只能聊天的插件，而是一层让 Agent 接入 X 的 MCP 接口。Agent 先读取和规划，主人确认后才执行写入，每一步都留下清晰的结果。
## TEST ACCOUNT
**先用一个测试账号跑通完整流程**
宣传视频先从测试账号开始。运行一条命令，Agent 会连接、检查账号、写出草稿、放入复核队列，再读取示例指标。页面会明确告诉观众：这是本地模拟，没有请求 X，也没有发布内容。
## MEASURED
**我们用实验数据说话**
这些数字有明确口径。512 个本地客户端的 HTTP mock 达到 994 RPS，错误为零。视觉兜底通过二十七项检查，六种视口和主题组合通过四十二项检查。真实 X 公开 profile 冷读约一到一点六秒。
## HONEST LIMITS
**边界也要一起展示**
我们也把限制放在画面上。一次内部 DSH 和 X 验收完成了三十一个动作，但耗时一百三十三秒，所以不能宣传成一分钟服务。两百次关注、每天五百条评论和页面级并行写入，目前都没有通过验收。
## TRY IT
**开发者可以马上复现**
现在就可以试。先运行 server.py 的 demo，看到本地测试账号和完整调用链，再运行 tester smoke 验证 MCP 握手。确认理解边界后，再用自己的专用浏览器配置做只读测试。
