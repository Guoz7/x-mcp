## 推文主文案

我们做了一个 X MCP，让 Agent 可以直接操作 X。

它不是只返回 API 数据：Agent 可以读取时间线、准备发帖和互动任务，再通过确认、租约和页面复验完成操作。

已验证：31 个连续互动动作，133 秒全部复验；单目标读取 p50 1.28 秒；MCP 一致性 39/39；DOM 优先，截图视觉兜底；stdio 和 Streamable HTTP 都支持。

GitHub：https://github.com/Guoz7/x-mcp

第一次体验：下载后运行 `tester.cmd setup`、`tester.cmd smoke`，再把 `ONE-CLICK-PROMPT.md` 复制给你的 Agent。

## 60 秒演示脚本

| 时间 | 画面 | 口播 |
|---|---|---|
| 0–8 秒 | Agent 对话框 | 以前 Agent 能写内容，却不能稳定完成 X 上的最后一步。现在给它一个 MCP。 |
| 8–18 秒 | `setup`、`smoke`、`config` | 安装、检查、生成配置，三步完成。 |
| 18–32 秒 | `tools/list`、公开资料和时间线 | Agent 先发现能力，再读取公开资料。 |
| 32–45 秒 | 目标、确认短语、action_id | 写操作先展示目标，用户确认后才执行。 |
| 45–55 秒 | DOM 失败后截图兜底 | 页面结构变化时，执行器用截图作为兜底，并再次确认状态。 |
| 55–60 秒 | 结果、耗时、证据哈希 | 每次动作都有结果、时间和证据。 |

## 与其他 MCP 组合的 Demo

### 内容工作台

连接：X MCP + 文件 MCP + 日历 MCP。

1. 文件 MCP 读取选题表。
2. Agent 生成候选文案。
3. 用户选择一条。
4. X MCP 生成发帖预览和确认短语。
5. 日历 MCP 保存发布时间。
6. 到时间后调用 X MCP 发布并复验。

### 研究到发布

连接：搜索 MCP + X MCP。

1. 搜索 MCP 获取主题资料。
2. Agent 生成带来源的摘要。
3. X MCP 读取相关公开帖子。
4. Agent 生成回复建议。
5. 用户确认一条回复。
6. X MCP 发布并返回 canonical URL。

### 发布后复盘

连接：X MCP + 表格 MCP + 文件 MCP。

1. X MCP 读取已发布帖子的公开互动数据。
2. 表格 MCP 记录时间、耗时和结果。
3. 文件 MCP 生成每日复盘报告。
4. Agent 给出下一条内容建议。

## 组合 MCP 的通用提示词

```text
你正在使用多个 MCP。先调用 tools/list，分别确认每个 MCP 的工具和权限。

任务：用内容 MCP 准备一条文案，用 X MCP 执行一次已确认的 X 动作。

流程：
1. 内容 MCP 只负责读取资料和生成候选文案。
2. X MCP 只负责读取公开页面、准备动作、执行确认后的动作和复验。
3. 展示目标 URL、完整文案、动作类型和确认短语前，不执行 X 写入。
4. 用户确认后只执行一个动作。每个动作使用独立 action_id 和租约。
5. 优先 DOM 或可访问性定位。失败时使用截图视觉兜底。
6. 页面状态无法确认时停止并报告 uncertain，不自动重试。
7. 最终返回每个 MCP 的调用、耗时、结果、证据 URL 和错误码。
8. 不读取 Cookie、密码、Token、私信或无关文件。
```
